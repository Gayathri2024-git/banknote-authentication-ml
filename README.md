# 🏦 Bank Note Authentication — ML Classification

## Project Overview
A machine learning classification project to 
authenticate banknotes as genuine or forged using 
statistical image features extracted from banknote 
photographs.

## Dataset
- **Source:** UCI Machine Learning Repository
- **Samples:** 1,373 banknotes
- **Features:** 4 statistical features
  - Variance of Wavelet Transformed image
  - Skewness of Wavelet Transformed image
  - Kurtosis of Wavelet Transformed image
  - Entropy of image
- **Target:** Class (Authentic / Forged)

## What I Did
- Data preprocessing and preparation
- Feature analysis and inspection
- Statistical feature engineering
- Multiple classifier training and comparison
- Hyperparameter tuning and optimization
- Model evaluation using performance metrics

## Technologies Used
- Python
- scikit-learn
- pandas
- NumPy
- Parquet data format

## Key Results
- Successfully built classification models to 
  distinguish authentic from forged banknotes
- Compared multiple classifiers through 
  hyperparameter tuning
- Achieved strong classification performance 
  on the test set
